WHAT IT ADDS
- When "Automatically update the bridge" is ON (Marlena
  confirmed Oct 23, 2026 that it is checked), the auto-check
  cycle (60 seconds after start, then every 24 hours, skipped
  while a print is running) now also runs an Action1 check,
  before the Bridge version check, in the same cycle.
- The Action1 auto-check:
  - Refreshes the tray menu check mark from live detection.
  - If an Action1 client is detected: logs that and does
    nothing else.
  - If no client is detected and NO installer path is saved:
    logs that only, and leaves the menu unchecked. It does
    NOT pop a file picker in the background — the operator
    picks the Action1 console download manually via the
    tray menu item, as before.
  - If no client is detected and an installer path WAS
    already picked and saved by the operator: attempts the
    install from that saved file, exactly as the manual
    menu item does. The Windows admin (UAC) prompt is
    still the gate — declining it installs nothing, and
    the check tries again next cycle. A failed attempt
    shows its result box; a successful one only logs.
- It never downloads an installer, never embeds an
  Action1 URL, token, or organisation name, and never
  installs when no installer was saved by the operator.
- The auto-check is posted back to the UI thread before
  it touches menu items, because the auto-update timer
  runs on a thread-pool thread and WinForms controls are
  not thread-safe.
