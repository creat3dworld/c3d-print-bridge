FIX INCLUDED (after a reported 2277 update failure)
- The 2277 update was reported as "failed to verify and
  rolled back" — that rollback is the installer's safety
  path: on a failed dotnet publish it restores the
  previous app files, with config and key preserved, so
  the bridge is left on its old version, not broken.
- Prime suspect, fixed here before 2278 is pushed:
  Action1Client.cs (2277) uses ServiceController and the
  Windows Registry, but C3DBridge.csproj had no explicit
  package reference for either. If those APIs are not in
  the shared framework on that PC, publish fails and the
  update rolls back exactly as reported. This build adds
  explicit references for both packages. Confirm against
  the shop PC build log (%TEMP%\C3DBridge-build.log,
  last 30 lines) before treating this as proven — if the
  log shows a different error, that error is the cause,
  not this one.
