WHAT CHANGED
- New local config field action1_download_url
  (Models.cs): blank in the repo example, real value
  only on the PC.
- Action1Client.DownloadAsync (new): downloads ONLY an
  https://…action1.com/…/agent/…msi link, into the bridge
  temp folder, rejects anything else, and never logs the
  link itself. IsValidDownloadUrl enforces that check.
- New Action1LinkForm: paste the console download link
  once (Endpoints -> Install Agent -> Other Options ->
  Direct download), with "Pick a file instead…" keeping
  the original 2277 file-picker flow.
- Tray Install Action1 client… (2282): if a download
  link is saved, it confirms, downloads from that link,
  then installs from the downloaded file (UAC prompt is
  still the gate). If no link and no file is saved, it
  shows the link prompt instead of a file picker first.
  Download + install run on a worker thread so a hung
  installer or a prompt on another display cannot freeze
  the tray menu.
- Action1 auto-check (2282): can now download from a
  saved link the same way. It never asks for a link or
  pops a result box in the background — it only logs, so
  a background check cannot block the tray with a dialog
  on an unseen display.
