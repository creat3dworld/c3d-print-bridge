WHAT IT ADDS
- Tray menu, after "Automatically update the bridge": a
  checkable item "Install Action1 client…".
- The check mark is LIVE DETECTION, not a toggle: checked
  means an Action1 agent was found on this PC, unchecked
  means none was found. Clicking it when checked only
  reports it is installed — it never uninstalls on uncheck.
- Clicking it when unchecked starts the install flow:
  1. If no installer path is saved locally, a file picker
     asks the operator to pick the Action1 agent installer
     they already downloaded from their own Action1 console.
     That path is saved in bridge-config.json ON THE PC
     ONLY (new field action1_installer_path).
  2. A confirm box names only the installer file name and
     says it installs the agent tied to the operator's
     Action1 account, so this PC will appear in their
     Action1 console for browser remote control.
  3. The installer runs ELEVATED (UAC prompt) with
     Action1's documented unattended args /quiet /norestart
     and a log at action1_install.log next to the exe.
  4. Success is only reported after re-detecting an agent
     on the machine — an exit code alone is never claimed
     as success.

HOW IT IS TIED TO THE ACCOUNT
- The Action1 agent installer downloaded from the Action1
  console carries that account's organisation binding in
  the file itself (Action1's docs note the file name
  contains profile-specific information, and renaming it
  requires passing the organisation name). The bridge
  therefore does NOT download an installer, does NOT embed
  an Action1 URL, token, or organisation name, and does
  NOT store any account detail. The account tie comes
  entirely from which console download the operator picks.
- Nothing account-related is committed to the repo: the
  example config leaves action1_installer_path blank, and
  a real path lives only in the local bridge-config.json.

DETECTION (no exact service name assumed)
- Any Windows service mentioning Action1, an Action1
  program folder, or an uninstall entry mentioning
  Action1. Any one signal counts as detected.
